> 🫶

## How it works

`main.py` holds the entry as a constant — the heart-hands emoji 🫶, an open, warm gesture that reads as kindness at a glance, with no words, no irony and nothing that needs context to land. It checks the entry against the kit's gate (UTF-8 text, 1–8 characters, not only whitespace, exactly one visible character, no control characters) and writes it to `/output/entry.txt` when run with `python3 main.py`.

Heart hands beat the default smiley on the judge's own brief: it feels picked for the moment rather than the first smiley that comes to mind, it is warm at first glance, and it works the same way for a stranger of any age or background — no intimacy, sarcasm or flirtation.
